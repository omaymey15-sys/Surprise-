# Surprise ♥️

Application Android (Kotlin) pour cacher des surprises avec un code à 14 chiffres.
Sans serveur à gérer : les données sont stockées dans Supabase (gratuit, sans carte bancaire).

- `app/` : application Android (`app/config.properties` = adresse et clé Supabase)
- `supabase.sql` : à exécuter une fois dans Supabase
- `DEPLOIEMENT.md` : guide complet, depuis un téléphone, avec GitHub Actions
